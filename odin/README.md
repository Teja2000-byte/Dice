# Odin workspace

Shared working folder for Odin tasks in the Dice repository.

- [Reviewer feedback checklist](Reviewer_Feedback_Checklist.md): lessons applied to current and future guides.
- [Narration standard](Narration_Standard.md): precise line numbers and control locations required in recording guides.
- `met.rtf`: Facility Opening Checklist metadata in Rich Text Format.
- `met.txt`: the same metadata as plain text for easy reading on GitHub.
- [InventoryImportReview](InventoryImportReview/README_FIRST.md): idea approved
  per user confirmation. Generated inputs, final numbered guide and complete
  recorder-transfer/recording-kit ZIPs are available. Input provenance is documented.

The metadata uses the revised approved Facility Opening Checklist Goal. Its
Topology follows the supplied recording guide; confirm it matches the actual
recording before submission. The submission guidelines call for the filename
`Metadata.rtf`, uploaded separately from `Deliverables.zip`.

This folder is separate from the Dice application files. GitHub and local
checkouts exchange changes through commits, pushes, and pulls; they do not
sync automatically.
