# Reviewer feedback applied to future recording guides

This checklist summarizes actionable lessons supplied by the user. It contains no original reviewer messages, task identifiers or reviewer identities.

| Area | Requirement for the guide and rehearsal |
| --- | --- |
| Code edits and deletions | Name the exact file, verified current physical line and nearby code. For each TODO/comment deletion, state the line and text before deleting it. Recalculate later lines after changes. |
| Browser fields | On every visit, name the field, its position relative to another visible control, the value being entered and why. Do not rely on a field location narrated several minutes earlier. |
| Buttons and click type | Say left-click, right-click or double-click as appropriate, then the actual button label, its visible location and purpose. |
| Scrolling and app switches | Announce the app/window, scroll direction and destination, or the destination app before changing focus. Identify selections with exact boundaries. |
| Clear speech | Use short, distinct sentences and normal speaking speed. Listen to a microphone test at normal playback speed. Avoid rushed, blended or mumbled words. |
| Consistent narration | Explain what, where and why while performing actions. Point to the target. State actual results. Avoid repeated silent clicks, delayed explanations and vague here/this/that references. |
| Errors | Explain the observed issue, location, established cause or investigation, correction and verified retest. Do not silently repair or invent errors. |
| Noise | Quiet room, room windows closed where practical, minimal traffic/voices/fan noise and headset microphone if available. Check a sample recording rather than assuming the microphone is clear. |
| Bookmarks and accounts | Hide the bookmarks toolbar before recording and inspect tabs/profile/autofill areas for project references and personal data. |
| Dock | Quit and unpin unused apps before the take. Keep required recording/accessibility apps and required background/security services running. |
| Epilogue | Rehearse 3-4 minutes, maximum four, covering outcome, verification, decisions, actual challenges, quality, limitations and improvements. A one-minute closing is not the planning target. |
| Resubmission | Review the new continuous recording and matching artifacts, run both AutoQC checks and apply the workflow checklist. Never edit the recording to remove a problem. |

The Inventory Import Review guide applies these rules to its own controls and code. Field names from earlier unrelated tasks must not be copied into this task. Verified input files and actual observations are still required before its draft becomes recording-ready.
